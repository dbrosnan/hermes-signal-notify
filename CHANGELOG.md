## [Unreleased]

## [1.1.0] - 2026-10-30

### Added

- A switch for each event in the Hermes Plugins settings: `notify_paused`, `notify_failed`,
  `notify_interrupted`, `notify_questions` and `notify_approvals`. Approvals and sudo
  prompts can now be turned off separately from clarify questions.
- `include_text` switch to send only the event and session, with no conversation text.
- Watercolor artwork for the README and the Hermes catalog page, generated by
  `docs/art/make_art.py`.

### Changed

- The switches replace the `notify_on` list in the settings form. An existing `notify_on`
  value still applies to any switch you have not set, so 1.0 configs behave the same.
- README: install from the Hermes plugin catalog by name; the GitHub URL is now the
  option for unreleased code.

## [1.0.0] - 2026-10-28

### Added

- Signal texts when a Hermes turn pauses, fails or is interrupted (`on_session_end`).
- Signal texts when Hermes waits on a clarify question, an approval or a sudo prompt
  (`on_human_input_request`).
- A preview of the final reply in the pause text (`post_llm_call`), capped by
  `reply_chars`.
- Settings: `recipient`, `notify_on`, `skip_platforms`, `reply_chars`.
- Skips Signal-origin, cron and subagent turns by default.
- Sends identical texts within 60 seconds only once, and sends one text per turn even
  when the CLI exit path reports the turn again.
- Community docs, issue and PR templates, CI with pinned actions, Dependabot and an
  OpenSSF Scorecard workflow.
